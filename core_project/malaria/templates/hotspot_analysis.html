This runs a Getis-Ord Gi* local statistic on each district's cumulative, population-adjusted incidence (cases per 10,000, the same figure the Dashboard hotspot map uses). Gi* tests whether a location's value and its neighbors' values are consistently high or low enough that the pattern is unlikely under complete spatial randomness — unlike a simple threshold map, a single unusually-high district surrounded by low neighbors will not register as a hot spot here.

Spatial weights: this project has no polygon/boundary shapefile for districts, only centroid coordinates, so "neighbor" is defined by k-nearest-neighbor distance (currently k={{ k }}) rather than shared borders — a standard substitute when only point locations are available (one of the built-in weighting options in tools like ArcGIS's own Hot Spot Analysis). Weights are binary (1 for a location's k nearest neighbors plus itself, 0 otherwise).

Formula: for each location i, Gi* = [Σ(xj for j in N(i)) − x̄ · Wi] / (S · √((n·Wi − Wi²) / (n−1))), where N(i) is location i's neighbor set (including itself), Wi = |N(i)|, x̄ and S are the global mean and population standard deviation of incidence across all {{ n_analyzed }} districts analyzed, and n = {{ n_analyzed }}. The result is a z-score: |z| ≥ 1.65 / 1.96 / 2.58 correspond to 90% / 95% / 99% confidence, with the sign giving the direction (positive = hot, negative = cold). Verified against synthetic test data with known clusters, and against 200 trials of pure spatial noise (no real clustering), where the false-positive rate came out at 10.0% / 4.9% / 0.6% for the three confidence bands — matching the 10% / 5% / 1% theoretical rate almost exactly.
