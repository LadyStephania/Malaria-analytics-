Worked out: {{ recent_cases }} confirmed cases ÷ {{ selected_district_population }} real population = 1 confirmed case per {{ incidence_one_in_n }} residents, which is the same as {{ incidence_per_10k }} per 10,000. This rate (not the raw case count) is what the burden tier and priority ranking are based on.

Next 7 Days' Weather checks each of the next 7 forecast days against two thresholds: a day is critical-risk if it has both heavy rain (over 10mm) and an ideal mosquito-breeding temperature (24–30°C) — the worst combination together. A day is moderate-risk if it has just some rain (over 2mm) or a warm temperature (20–32°C) on its own, without the other condition. {{ target_label }}: {{ danger_days_7 }} of the next 7 days are critical-risk, {{ warning_days_7 }} are moderate-risk.
