Data Quality

How complete is each district's reporting history, and is it up to date? Real HMIS data is rarely 100% complete — this page shows exactly where the gaps are instead of hiding them.

What this does and doesn't measure: completeness and "up to date" status below are computed from the reporting periods actually on file for each district, compared against every period reported anywhere in the dataset. This is district-level data — there's no facility-level breakdown to report on. It also can't show true submission timeliness (how many days late a report was against a deadline), because the uploaded records only carry the reporting period itself, not a separate submission date. "Up to date" below is a proxy: whether a district's most recent report matches the most recent period anywhere in the data.
