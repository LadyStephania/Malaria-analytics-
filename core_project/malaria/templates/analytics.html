Correlation Model Methodology

This view computes a Pearson correlation coefficient (r) between the selected environmental driver and RDT-confirmed case counts, offset by the chosen lag window to approximate the mosquito breeding-to-clinical-presentation delay. Statistical significance is estimated via a Fisher z-transformation of r, converted to a two-tailed p-value against the sample size shown above. Adjust the driver and lag controls to explore how the relationship shifts across different environmental variables and time offsets.

Random Forest Methodology

A Random Forest Regressor (200 trees, depth-limited to guard against overfitting on a dataset this size) is trained to predict a district's confirmed cases from rainfall and temperature lagged by the same window selected above, plus that district's own prior-period case count. Unlike the correlation panel, it's evaluated with a time-based holdout — trained only on {{ cadence_unit }}s before {{ rf_test_year }}, then scored strictly on {{ rf_test_year }}, data it never saw during training — so the R² and MAE above reflect genuine forecasting skill on unseen data, not fit to data it already memorized.
