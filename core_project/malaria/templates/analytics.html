Correlation

This page computes a Pearson correlation coefficient (r) between the selected environmental driver and RDT-confirmed case counts, offset by the chosen lag window to approximate the mosquito breeding-to-clinical-presentation delay. Statistical significance is estimated via a Fisher z-transformation of r, converted to a two-tailed p-value against the sample size shown above. {% if has_data %}Current result: r = {{ correlation_r }}, p = {{ p_value }}, n = {{ sample_size }}.{% endif %}

Prediction model

A Random Forest Regressor (200 trees, depth-limited to guard against overfitting on a dataset this size) is trained to predict a district's confirmed cases from rainfall and temperature lagged by the same window selected above, plus that district's own prior-period case count. It's evaluated with a time-based holdout — trained only on {{ cadence_unit }}s before {{ rf_test_year }}, then scored strictly on {{ rf_test_year }}, data it never saw during training. Current result: R² = {{ rf_r2 }}, MAE = ±{{ rf_mae }}, trained on {{ rf_n_train }} records, tested on {{ rf_n_test }}.
